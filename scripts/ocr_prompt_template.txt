# 詳細データOCRのエージェント用プロンプト雛形
# 使い方: {DATE}（例 2026-09-09）と {OUT_DIR}（JSON出力先）を置換し、
#         {RANKS} に担当ランク（3桁ゼロ埋め・8件程度）を入れて Agent に渡す。
# 実行前に crop_panels.py → shrink_panels.py を必ず通すこと（_s_*.png を読む前提）。
# 詳細な手順は .claude/skills/ ではなくメモ pokenavi-champions-crawl を参照。

ポケモンゲームのスクリーンショットを読み取り、JSONファイルに書き出す作業です。

対象フォルダ: /Users/shigeki/work/pokenavi/crawl_data/champ_crawl_{DATE}/detail/{RANKS}

【重要】Agentツールでサブエージェントを起動しないこと。指定された全ランクを自分で最後まで処理し、終わるまで報告しないこと。

【重要・トークン節約】各ランクにつき、そのフォルダの `_s_*.png` 18枚を**1回のメッセージ内でまとめてRead**（縮小済みなので軽い）し、直後にJSONをWriteしてください。1枚ずつ読まないこと。1ランク終えたら次のランクへ進みます。

各フォルダの画像:
- `_s_ability_00.png` … 上部ヘッダーに「N位 No.XXX ポケモン名」、下に「特性」パネル（順位・名前・採用率%）
- `_s_move_00.png`, `_s_move_01.png` … 「技」パネル（1〜5位 / 6〜10位）
- `_s_item_00.png`, `_s_item_01.png` … 「持ち物」パネル
- `_s_nature_00.png`, `_s_nature_01.png` … 「能力補正（性格）」パネル
- `_s_partner_00.png`, `_s_partner_01.png` … 「同じチームのポケモン」パネル（順位とポケモン名のみ。%はない）
- `_s_ev_00.png` 〜 `_s_ev_08.png` … 「能力ポイント」パネル。スクロールした連続ページなので**行が重複します**。各行は H/A/B/C/D/S の6数値と採用率%。重複行は1つにまとめ、上から出現順に並べること

出力先: {OUT_DIR}/{rank3桁}.json

```json
{
  "rank": 1,
  "pokemon": "ガブリアス",
  "moves":     [{"name":"じしん","rate":99.2}],
  "items":     [{"name":"きあいのタスキ","rate":41.4}],
  "abilities": [{"name":"さめはだ","rate":99.1}],
  "natures":   [{"name":"ようき","rate":51.8}],
  "partners":  [{"name":"カバルドン"}],
  "evs":       [{"h":2,"a":32,"b":0,"c":0,"d":0,"s":32,"rate":50.3}]
}
```

注意:
- 数値・%は画像に表示されている通り正確に。推測・丸めをしない
- ポケモン名・技名・持ち物名・特性名は画面表記のまま（ひらがな/カタカナを変えない）。読めない文字を勝手に既知の名前へ直さない
- 性格名は名前部分のみ（「（S↑ C↓）」は含めない）
- 項目が10件未満・パネルが1ページのみの場合はある通りに
- EVの数値は0〜32の範囲

完了したら「書き出したファイル名とポケモン名」だけを1行ずつ簡潔に報告してください。JSON全文は報告しないこと。
