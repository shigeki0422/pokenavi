## ポケモンチャンピオンズとは

ポケモンチャンピオンズは、歴代シリーズのポケモンが一堂に会する対戦プラットフォームです。**メガシンカが使用可能**な点が大きな特徴で、リザードンX・Y、メガルカリオといった強力なメガシンカポケモンが環境に大きく影響しています。

## 深掘り①：ガブリアス（1位）

### なぜ1位なのか

ガブリアスが首位を維持し続ける理由を採用データから読み解きます。

**採用技ランキング（採用率5%以上）**

| 技 | 採用率 |
|----|--------|
| じしん | 99.2% |
| ステルスロック | 51.9% |
| げきりん | 49.0% |
| がんせきふうじ | 40.3% |
| スケイルショット | 33.0% |
| いわなだれ | 23.6% |
| どくづき | 19.6% |
| ドラゴンテール | 18.8% |

**持ち物内訳**

| 持ち物 | 採用率 |
|--------|--------|
| きあいのタスキ | 37.5% |
| こだわりスカーフ | 34.5% |
| オボンのみ | 16.0% |

### 読み取れること

じしんの採用率99.2%はほぼ確定技です。一方でステルスロック（51.9%）とげきりん（49.0%）がほぼ半々に分かれており、**「起点型」と「アタッカー型」の2つの型が環境に共存**していることがわかります。

持ち物でも「きあいのタスキ（起点型）」と「こだわりスカーフ（スカーフ型）」が拮抗しており、相手から型を読まれにくい多様性が使用率1位の一因と考えられます。

## データサイエンスの視点：使用率はどう計算されるか

champs.pokedb.tokyoは上位構築データをCSV・JSON形式で公開しています。使用率はこのデータから以下の計算で求められます。

```python
import pandas as pd
import requests

# M-1シーズンのデータを取得
url = "https://champs.pokedb.tokyo/opendata/s1_single_ranked_teams.csv"
df = pd.read_csv(url)

# 各スロットのポケモン列を結合して使用頻度を集計
pokemon_cols = [f'ポケモン_{i}' for i in range(1, 7)]
all_pokemon = pd.concat([df[col] for col in pokemon_cols])

# 使用率を計算（総チーム数 × 6体で割る）
usage_rate = all_pokemon.value_counts() / len(df) * 100
print(usage_rate.head(20))
```

## まとめ：M-2環境の3つの特徴

1. **メガシンカ持ちが上位を席巻**：TOP20のうちリザードン・ルカリオ・ミミロップ・ハッサム・スターミーがメガシンカ採用
2. **ガブリアスの多様性が強さの源**：起点型・スカーフ型の読み合いが生じることで対策が困難
3. **歴代人気ポケモンが多数ランクイン**：ギャラドス・ゲンガー・カイリューなど、複数世代のポケモンが活躍
