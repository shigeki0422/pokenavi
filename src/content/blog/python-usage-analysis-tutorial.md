今回は **[champs.pokedb.tokyo](https://champs.pokedb.tokyo) が公開している生データをPythonで取得・分析する方法** を解説します。コードをそのままコピーして実行できます。

## データの入手先

champs.pokedb.tokyoは上位構築データをCSV・JSON形式で無償公開しています。

```
https://champs.pokedb.tokyo/opendata/s{シーズン番号}_{single|double}_ranked_teams.csv
```

M-1シングルバトルのURLはこちらです：

```
https://champs.pokedb.tokyo/opendata/s1_single_ranked_teams.csv
```

> **利用上の注意**：サーバーへの過度なアクセスはご遠慮ください。分析結果をアプリ等で配信する場合は自サーバーにキャッシュしてご利用ください（[利用ガイドライン](https://champs.pokedb.tokyo/guide/opendata)）。

## Step 1：データ取得とデータ構造の確認

```python
import pandas as pd

# M-1データ取得
url = "https://champs.pokedb.tokyo/opendata/s1_single_ranked_teams.csv"
df = pd.read_csv(url)

print(f"総チーム数: {len(df)}")  # → 522チーム
print(df.columns.tolist()[:10])
```

出力：

```
総チーム数: 522
['順位', 'レート', 'ポケモンID_1', 'ポケモン_1', 'フォルム_1',
 'タイプ1_1', 'タイプ2_1', 'カテゴリー_1', 'テラスタイプ_1', '持ち物_1']
```

データは**1行＝1チーム（6体）**の横持ち形式です。ポケモン1〜6それぞれにID・名前・技・持ち物の列があります。M-1は上位**522チーム**が収録されています。

## Step 2：使用率を計算する

使用率の定義は「全チーム中、そのポケモンを採用したチームの割合」です。

```python
# 6スロット分のポケモン名列を縦に結合
pokemon_cols = [f'ポケモン_{i}' for i in range(1, 7)]
all_pokemon = pd.concat([df[col] for col in pokemon_cols])

# 使用率（%）計算
usage_rate = (all_pokemon.value_counts() / len(df) * 100).round(1)
print(usage_rate.head(20))
```

## Step 4：持ち物分析

特定ポケモンの持ち物分布も簡単に集計できます。

```python
# ガブリアスの持ち物を集計
gabrias_items = []
for i in range(1, 7):
    mask = df[f'ポケモン_{i}'] == 'ガブリアス'
    gabrias_items.extend(df.loc[mask, f'持ち物_{i}'].dropna().tolist())

item_rate = (pd.Series(gabrias_items).value_counts() 
             / len(gabrias_items) * 100).round(1)
print(item_rate.head(5))
```

**ガブリアス 持ち物分布（M-1実データ）**

| 持ち物 | 採用率 |
|--------|--------|
| こだわりスカーフ | 37.1% |
| きあいのタスキ | 26.2% |
| オボンのみ | 22.2% |
| ラムのみ | 9.8% |
| ハバンのみ | 3.3% |

M-2のガブリアス（M-2データ：スカーフ34.5%、タスキ37.5%）と比べると、**M-2ではタスキ型が増加**していることがわかります。対面重視のプレイスタイルへのシフトが読み取れます。

## まとめ：データで読む環境変化の意味

今回のPython分析でわかったこと：

1. **ガブリアスは圧倒的な採用率**でM-1・M-2ともに1位。環境の基盤ポケモンとして確立
2. **マスカーニャ・リザードン・ルカリオがM-2で急浮上**。研究の進行による評価の変化
3. **持ち物の比率変化**がプレイスタイルのトレンドを映している（M-1スカーフ優勢 → M-2タスキ優勢）
